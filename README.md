## Things I've built

### 🔧 [jfzc-hcc.github.io](https://jfzc-hcc.github.io/) — personal blog & portfolio

A statically generated site I started from an [Astro](https://astro.build) template and have been extending ever since. It's where I practise front-end work and build my own tooling.

**Stack:** Astro 7 · Tailwind CSS 4 · TypeScript · Markdown + Content Collections · GitHub Actions → GitHub Pages

**Engineering I'm proud of:**

- A two-layer cross-fading background carousel that auto-discovers images, preloads the next frame, skips files that fail to load, and never flashes to an empty background
- `[[wiki-link]]` syntax with automatically generated backlinks, implemented as a custom remark plugin
- A build-time content pipeline: word counts, estimated reading time, and an integration that auto-creates a per-article asset folder for every new post
- A config-driven page system where each page is assembled from typed modules declared in one config file, instead of being hand-written per route

**What it taught me:** Astro's routing and content collections, component composition, build-time data pipelines, writing custom remark plugins, and how CI/CD behaves when you push.
